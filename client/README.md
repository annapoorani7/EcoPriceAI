# Predictive Dynamic Pricing and Revenue Management System for Eco-Tourism Hospitality

A comprehensive MERN Stack application for dynamic pricing and revenue management in eco-tourism hospitality. This is the React frontend providing an intuitive interface for managing hotel pricing, bookings, analytics, and revenue optimization.

## Features

- **Authentication System** - User registration and login with JWT
- **Dashboard** - Real-time metrics, revenue tracking, occupancy monitoring
- **Dynamic Pricing Engine** - AI-powered price predictions with demand-based pricing
- **Event Analysis** - Track events and their impact on pricing/occupancy
- **Revenue Analytics** - Monthly reports, trend analysis, and performance metrics
- **Booking Management** - View, filter, and manage bookings
- **Hotel Management** - Manage hotel information and amenities
- **User Profile** - Profile customization and preferences

## Quick Start

### Prerequisites
- Node.js 14.x or higher
- npm 6.x or higher

### Installation

```bash
# Install dependencies
npm install

# Setup environment
cp .env.example .env

# Start development server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
